## About me

I'm an engineering student at the **National Institute of Posts and Telecommunications (INPT)**, focused primarily on **Cloud and DevOps engineering**.

I enjoy understanding how systems are designed, connected, automated and operated. My interests include:

- ☁️ **Cloud & DevOps:** cloud infrastructure, containers, orchestration, Infrastructure as Code and CI/CD.
- 🔐 **DevSecOps:** integrating security and quality checks throughout the software delivery lifecycle.
- 🌐 **Networking:** network architecture, connectivity, cloud networking and software-defined networking.
- 🤖 **AI & Data:** machine learning, intelligent monitoring and data-driven infrastructure.

I'm interested in the bigger picture: how software, infrastructure, networks and automation work together to build dependable systems.
